Step 1 — Show the 51 invalid values

Server: Local Windows PC
IP: 127.0.0.1

Run:

$invalid |
Where-Object {
    $ttNo = ([string]$_.tt_no).Trim()

    -not [string]::IsNullOrWhiteSpace($ttNo)
} |
Select-Object `
    id,
    tt_no,
    fault_date_time,
    client_name,
    employee_id |
Format-Table -AutoSize

Then group the exact invalid values:

$invalid |
Where-Object {
    -not [string]::IsNullOrWhiteSpace(
        ([string]$_.tt_no).Trim()
    )
} |
Group-Object tt_no |
Select-Object Name, Count |
Sort-Object Count -Descending |
Format-Table -AutoSize

This will reveal whether the values contain:

decimal points
apostrophes
spaces inside the number
hyphens
text values
damaged numbers
